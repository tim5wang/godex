## What This Demo Shows

GoDex Local Task Center TUI turns local agent work into a visible, guided workflow: pick a task, watch progress, review outputs, and merge only what is ready.

## Task Center

The Task Center gives users a single place to see active, queued, and completed local tasks without digging through terminals or logs.

## Workers

Workers make parallel local execution understandable by showing which agent is handling each task, what it is doing, and whether attention is needed.

## Review And Merge

Review and merge keeps users in control by surfacing changed files, summaries, and merge readiness before any work lands in the main workspace.

## Next Product Step

The next step is to connect this MVP flow to real task templates, richer status signals, and a lightweight review path that supports daily developer use.
