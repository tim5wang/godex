# Example Skills

Put checked-in example skills here using the directory layout:

```text
examples/skills/<name>/SKILL.md
```

Installed local runtime skills belong in `.godex/skills/`.

Current examples:

- `browser-assist`: browser handoff/resume workflow for user-gated web automation.
- `package-developer`: Godex package creation, testing, install, reinstall, uninstall, smoke, and diagnostics workflow.
