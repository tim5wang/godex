## 设计令牌

| 令牌 | 值 | 说明 |
|---|---|---|
| `--wg-bg` | `#04070a` | 近纯黑底，AMOLED 省电 |
| `--wg-surface` / `-2` / `-3` | `#0e1417` / `#161d21` / `#1e272c` | 卡片 / 次级 / 高亮面 |
| `--wg-text` / `--wg-muted` / `--wg-dim` | `#e7eef2` / `#9aa9b1` / `#66757d` | 主 / 次 / 辅助文字 |
| `--wg-accent` | `#14b8a6` | godex teal（Web UI `#0f766e` 在小屏提亮） |
| `--wg-ok` / `--wg-busy` / `--wg-warn` / `--wg-danger` | `#22c55e` / `#38bdf8` / `#f59e0b` / `#ef4444` | 完成 / 运行中 / 待办 / 高危 |

语义映射（全稿一致）：**运行中=蓝、待审批=红、完成=绿、离线=灰**。颜色旁必须同时有文案或图标，不单靠颜色传意。

## 圆屏约束

- 基准 456×456（Pixel Watch 3 45mm）；**480×480（小米 Watch 5 原生基准，也是 Vela/框架默认）**；Galaxy Watch 7 同为 480×480。等比缩放即可。
- 外圈 24px 内不放可点元素；正文左右留 22–24px。
- 三段式：顶部 26–30px 状态行 / 中部滚动区 / 底部 22–26px 操作行。
- 触控目标 ≥ 48dp：圆钮 62dp、主按钮 78dp、全宽按钮高 ≈ 48dp。
- 列表全部支持旋转表冠 / 表圈（rotary input），并保留「点按即用」的降级路径。
- **不使用水平滑动承载业务语义**：Wear OS 3+ 系统右滑 = 退出/返回，与「左右滑切任务/设备」类设计冲突。滚动一律用旋表冠，进出用显式按钮/chip。
- 输入以「说一句话 + 点一下」为主；文本输入只作备选（圆屏键盘体验差）。
- 待机/常亮态只显示极少量信息（运行中任务数），不做动画。

## 两个正交状态（切设备 vs 切会话）

| 状态 | 含义 | 位置 | 稿件 |
|---|---|---|---|
| **当前目标设备** | 指令发给哪台 godex（PC / 手机 / 云端） | 顶部 chip | 03 / 09 |
| **当前会话** | 指令落在哪条会话（从属于当前设备） | 底部胶囊 | 03 / 13 |

- 切设备 → 会话列表整体换成该设备的，并自动选中它最近活跃的会话。
- 切会话 → 不改设备。
- **待审批队列跨设备统一且不可筛选**（稿件 15）：无论当前遥控哪台，所有在线端点上等你决定的事都在这里。
- 跨设备列表的筛选 chips 只是**视图**，不改变「指令默认发给谁」（稿件 14）。
