<godex-step> 嵌入组件 Demo

这是 Phase C 的最小演示：直接 <script> 引入打包产物 dist/embed/godex-step.js，然后放一个 <godex-step> 标签即可得到一个 Agent 交互块。真实使用时替换 api-key 为你的 biz_ 业务系统 key。

示例 1：基础（含知识库召回 + 结构化输出）

示例 2：仅本地开发（vite proxy 到 127.0.0.1:8080）

本地起 godex serve 后，把 base-url 留空（页面由 godex 自己 serve 时无需 base-url）。

接入方式

<script src="dist/embed/godex-step.js"></script>
<godex-step
  base-url="https://godex.claw.carc.top"
  api-key="biz_xxx"
  prompt="分析订单 ORD-1234"
  inputs='{"order_id":"ORD-1234"}'
  context='{"recall":["godex://memory"]}'
  tools='{"sandbox":["read_file"]}'
></godex-step>

属性说明：base-url（godex 服务地址，godex 自带页面时可省略）、 api-key（必填，biz_ 业务系统 key）、prompt（初始指令）、 inputs / context / tools（JSON 字符串，对应 createStep 请求体字段）。
