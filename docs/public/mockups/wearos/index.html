GoDex Wear OS 客户端 · UI 设计稿

圆屏 456×456（Pixel Watch 3 45mm；Galaxy Watch 7 为 480×480，同比例）。深色优先，强调色沿用 godex Web UI 的 teal 家族（#0f766e → 小屏提亮 #14b8a6）。

定位：腕上遥控器 + 通知硬件——不在手表上跑 agent；输入是「按几个按钮 + 说一句话」，输出是「瞥一眼就知道」。

两个正交状态：当前目标设备（发给哪台，顶部 chip）× 当前会话（落哪条，底部胶囊）。切换入口分别见 09 与 13。

圆屏安全区（15 张稿统一遵守）

  • 外圈 24px 内不放可点元素（表壳遮挡 + 防误触）；正文左右各留 22–24px。
  • 顶部 26–30px 为时间/状态行，底部 22–26px 为操作行；中间为唯一滚动区。
  • 点击目标 ≥ 48×48dp：圆钮 62dp，主按钮 78dp。
  • 可滚动列表均支持旋转表冠 / 表圈（rotary input），不依赖精确点按。
  • 不使用水平滑动承载业务语义——系统右滑 = 退出/返回，手势冲突见 PRD §7.7。

怎么打开

  • 直接双击 index.html（无需构建、无外部依赖，纯 HTML + 内联 SVG）。
  • 每张稿也能单独打开，例如 06-approval.html，方便截图进需求文档。
  • 也可在文档站访问：/mockups/wearos/（docs/public/ 已自动静态托管）。
